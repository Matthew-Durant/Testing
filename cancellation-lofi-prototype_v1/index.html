Moderator notes

Reset sits bottom right on every screen. It clears session state, the days-to-departure override and the event log, then returns here. Run it between participants.

Event log. Type LOFI.events() in the browser console at any point to read the exact sequence fired in this session.

Conformance. Type LOFI.audit() on any screen to check computed styles for chromatic colour, tap targets and screen headings.

Inert controls. The Extras and Documents tabs, and the amend, edit and payment links on the trip summary, are present but do nothing. They are in the stimulus because removing them would change what the cancellation route competes against. Everything else on the cancel path is live.
