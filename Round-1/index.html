MMB cancellation, Round 1

Three flows, one booking, one fee schedule. The only thing that changes between them is how much has been paid, which is what decides whether the customer gets money back, gets nothing back, or owes money. Everything is offline: open this file from disk with wifi off and the whole package works.

Move the scenario across the fee schedule

Today is always the participant's real date. Departure is computed as today plus the days-to-departure value, so every date, day count and amount on every screen recomputes together. The default is 83 days, which reproduces the source design exactly and puts the participant in the loss-of-deposit band with 13 days left in it. Add ?dtd=N to any entry link to move. The value persists for the session; garbage input falls back to 83.

Flow 2 only completes online in the loss-of-deposit band One rule decides the route in every flow: if today's charge is larger than the amount paid, the customer owes money and there is no online payment path, so the flow goes to the contact centre. A deposit-only customer is past that point the moment the percentage bands start, so any Flow 2 link at fewer than 71 days behaves like Flow 3. That is the design working correctly, not a bug, but it is worth knowing before you move Flow 2 and worth reading as a finding in its own right.

Moderator notes

Reset sits bottom right on every screen. It clears session state, the days-to-departure override, the cancelled flag and the event log, then returns here. Run it between participants and between flows: a completed cancellation marks that booking cancelled for the rest of the session.

Event log. Type LOFI.events() in the browser console at any point to read the exact sequence fired in this session. Every event carries the flow it came from.

Conformance. Type LOFI.audit() on any screen to check computed styles for chromatic colour, tap targets and screen headings.

Inert controls. The Extras and Documents tabs, the amend, edit and payment links, and the Make a payment button are present but do nothing. They are in the stimulus because removing them would change what the cancellation route competes against for attention. Everything else on the cancel path is live.
